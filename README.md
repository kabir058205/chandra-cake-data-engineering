# Project: Chandra Cake – Data Engineering Pipeline

## Project Overview

Chandra Cake is an end-to-end **data engineering project** designed to demonstrate a modern analytics data pipeline using the **Medallion Architecture (Bronze, Silver, Gold)** on Databricks.

The project simulates a real-world cake manufacturing and selling business, covering raw material purchases, customer orders, and sales analytics.

---

## Business Context

Chandra Cake is a cake manufacturing & selling business that performs the following operations:

* Buys **raw materials** (flour, sugar, eggs, butter, cocoa, cake box boards, etc.)
* Uses these materials to **produce cakes**
* **Sells cakes** to customers based on orders

The goal of this project is to convert raw operational data into **clean, analytics-ready datasets** and generate **business insights**.

---

## Key Entities

The pipeline is built around the following core business entities:

* **Material Master** – List of raw materials and packaging items
* **Material Purchase (Expense)** – Records of material procurement transactions
* **Customer Master** – Customer details
* **Sales Orders** – Cake orders placed by customers

---

## Source Data

The source data is provided as CSV files and stored in a Databricks Volume or cloud storage location.

### Source Files

* `material_master.csv`
* `material_purchase.csv`
* `customer_master.csv`
* `sales_orders.csv`

Each file represents data generated by a source system and is ingested without modification into the Bronze layer.

---

## Pipeline Architecture

The pipeline follows the **Medallion Architecture** pattern:

### Bronze Layer (Raw Zone)

* Stores raw ingested data as-is from source files
* No transformations applied
